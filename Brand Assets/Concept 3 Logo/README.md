# Brand Here Concept 3 Logo

This folder records the approved Concept 3 wordmark direction.

## Design decision

- `BRAND` uses a semi-bold modern sans serif to express strategic confidence and operational substance.
- `HERE` remains refined and lighter in Signal Red, providing the distinctive human and editorial signal.
- The two words should never use equal weight.
- The wordmark should not be stretched, condensed, outlined or given effects.

## Files

- `brand-here-primary-light.svg` — approved colour wordmark on Digital Ivory.
- `brand-here-primary-dark.svg` — approved reversed wordmark on Carbon.
- `brand-here-primary-transparent.svg` — transparent colour master for light backgrounds.
- `brand-here-one-colour.svg` — one-colour Carbon production version.

## Typeface

- BRAND: Manrope SemiBold 600.
- HERE: Italiana Regular 400.
- If producing final outlined artwork for printers, open the SVG with the approved fonts installed and convert the text to vector outlines before release.

## Colour

- Signal Red: PANTONE 179 C / `#E03C31`.
- Carbon: PANTONE Black C / `#2D2926`.
- Warm Bone: PANTONE 7527 C / `#D6D2C4`.
- Digital Ivory: `#F3F0E8`.

See `../../BRAND-COLOUR-SYSTEM-CONCEPT-3.md` for the complete colour and production rules.
