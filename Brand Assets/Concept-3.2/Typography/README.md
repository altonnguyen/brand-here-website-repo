# Brand Here Concept 3.2 — Website Typography Assets

Status: Supporting brand assets for the approved website typography system  
Governing decision: BH-2026-010  
Added: 1 September 2026

## Active website typefaces

- **Playfair Display** — display and editorial typography in English and Vietnamese. The approved website uses weights 400–500 plus italic 400.
- **Manrope** — body copy, navigation, interface, metadata, cards, forms, captions and footer content. The approved website uses weights 300–600.

The variable font files in this folder include the required approved weight ranges. They are retained as source/design assets; adding them here does not change the production website's existing Google Fonts loading method.

- `Playfair Display/PlayfairDisplay-VariableFont_wght.ttf`
