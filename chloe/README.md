# Nguyễn Thảo Nhi (Chloe) — Brand Here digital namecard

Production URL: https://brandhere.co/chloe/

Master logo is referenced from `../images/homepage-2026/brand-here-master-color.svg`. Fonts: Playfair Display and Manrope. QR embeds the vCard. Physical NFC tags should use an NDEF URL record to `https://brandhere.co/chloe/`. The share button invokes the native file share sheet, falling back to PNG download. Apple Wallet requires a Pass Type ID certificate and its private signing key.
