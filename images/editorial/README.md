# Concept 3.2 editorial image drop

Use approved 1200 × 630 JPG raster assets only. The page slots retain their stable no-image state until the file named in each slot's `data-image-src` exists. `js/editorial-images.js` checks on intersection, then inserts a 1200 × 630 image with `loading="lazy"`, asynchronous decoding, and the governed EN/VI alt text.
